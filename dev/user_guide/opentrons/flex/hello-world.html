Opentrons Flex#

Opentrons
Flex
Basicv1
liquid handler
liquid handling
APIpylabrobot.opentrons.Flex
NotesHardware verification is operation-specific; 1-channel and 96-channel heads remain unverified.
code

This guide covers discovery, connection, deck setup, full-column and single-nozzle pipetting, partial-column tip pickup, tip and volume tracking, liquid-handling parameters, optional gripper moves, and shutdown. The runnable examples use an 8-channel Flex pipette and a 50 µL tip rack. See the final section for other heads and lower-level operations.

Property

Value

Connection

Robot-server HTTP API on port 31950

Discovery

Local-network mDNS with find_flex_ip()

Device

Flex; pipettes at flex.left_pipette, flex.right_pipette, or flex.head96

Units

µL for volume, µL/s for flow, mm for positions and offsets

Deck in this guide

Tips D1, plate B1, trash A3; B2 reserved for optional gripper moves

Warning

These cells control real hardware. Setup homes the robot; pipetting, gripper, and shutdown cells move it. Run deliberately, keep the deck clear of hands, close the enclosure, and keep the emergency stop accessible.

Hardware verification is operation-specific. The driver records prior checks for some 8-channel and gripper operations, while other operations and the 1-channel and 96-channel heads remain unverified. This guide does not establish hardware validation for your pipette, labware, calibration, or software version. Partial pickup below is an optional bench-validation example.

Install and import#

Install pip install 'pylabrobot[opentrons]' in the notebook’s Python environment. Connect the computer and robot to the same local network. Discovery reads live advertisements; it does not depend on the Opentrons app’s cached robot list.

The driver sends commands to the robot’s HTTP API. The deck describes physical labware locations; pipetting methods belong to a mounted head. The resource plate geometry below comes from PLR. Aspiration and dispensing move to PLR coordinates, then operate in place; the robot does not resolve the plate geometry. Use the resource definition matching your physical plate, including its cavity floor.

from pylabrobot.opentrons import Flex, FlexHead8, find_flex_ip
from pylabrobot.resources import cor_96_wellplate_360uL_Fb, set_tip_tracking, set_volume_tracking
from pylabrobot.resources.opentrons import (
  FlexDeck,
  flex_96_filtertiprack_50ul,
)

Prepare the physical deck#

Start with no tips mounted. Load a fresh Flex 50 µL tip rack in D1 and a Corning 96-well 360 µL flat-bottom plate in B1. Add 100 µL of water to each well A1–H1. Confirm the pipette supports these tips and the example volumes. Leave A1 and C1 empty so inactive nozzles have clearance; keep other labware out of rows A and C except the configured trash in A3. Leave B2 empty for the optional plate move.

For a single or partial pickup, all eight nozzles descend even though only some receive tips. With the front H1 nozzle selected, unused nozzles extend behind the target. This is why these examples use deck rows B and D.

Nozzle selection

Channel numbers identify pipette nozzles, not tip-rack rows or plate wells. The notebook uses rack column 1 for eight tips, A2 for one tip, and A4–D4 for four tips. Run each pickup once per fresh rack. Do not rerun setup to make used tips appear available in software.

deck = FlexDeck()
tip_rack = flex_96_filtertiprack_50ul(name="tips_01")
plate = cor_96_wellplate_360uL_Fb(name="plate_01")
deck.assign_child_at_slot(tip_rack, "D1")
deck.assign_child_at_slot(plate, "B1")
trash = deck.get_trash_area()

Track tips and liquid#

Enable tracking so missing tips and insufficient liquid can be rejected before a command is sent. Initialize volumes to the actual water you added. These trackers describe expected state; they do not measure the deck or liquid. The examples return each aspirated volume to its source well.

Pickup, tip drop, and well/container aspirate/dispense operations finish by lifting vertically to at least flex.traversal_height. Model every deck obstacle so taller labware raises this clearance. In-place operations and explicit positioning keep their requested position; position above the intended well before an in-place blowout.

set_tip_tracking(True)
set_volume_tracking(True)
for well in plate.column(0):
  well.tracker.set_volume(100)

Discover and connect without motion#

find_flex_ip() returns the sole Flex address advertised on the local network. If more than one is present, use find_flex_ip(name="My Flex") with the exact advertised robot name. It raises an error for missing or ambiguous results. You can also pass a known IP address directly as host.

connect() reads robot health without creating a run or homing. Check the reported robot before continuing. setup() in the next section takes control of the robot and homes it.

flex = Flex(host=find_flex_ip(), deck=deck)
await flex.connect()
print("host:", flex.host)
print("software version:", flex.software_version)
print("robot model:", flex.robot_model)

Set up and select the head#

After checking the physical deck, run setup(). It checks the connection, creates a control run, homes all axes, and loads the mounted instruments. The robot’s touchscreen is occupied while the run is active.

Set MOUNT to the mount carrying your 8-channel pipette. flex.head96 is used instead for a 96-channel head; those examples are not interchangeable with this 8-channel protocol. A standalone await flex.home() can home again when needed; there is no need to repeat it immediately after setup.

await flex.setup()
MOUNT = "left"  # Change to "right" if that is where your 8-channel pipette is mounted.
head = {"left": flex.left_pipette, "right": flex.right_pipette}[MOUNT]
assert isinstance(head, FlexHead8), f"Expected an 8-channel head on {MOUNT}, got {head}"
print("mounted tips:", head.get_mounted_tips())
print("gripper:", flex.gripper)
print("traversal height:", flex.traversal_height)

Full column: pick up eight tips#

column(0) means the first column, A1–H1. Pass the tip spots directly to pick_up_tips(). With no use_channels argument, a full column uses all eight nozzles. Labware is loaded into the robot’s run as needed.

await head.pick_up_tips(tip_rack.column(0))
print("mounted tips:", head.get_mounted_tips())

Check tip presence#

Pickup checks the pipette’s hardware tip sensor before committing PLR’s tip state. has_tip_on_hardware() returns a pipette-level reading (True, False, or None when unavailable), not eight independent nozzle readings. get_mounted_tips() is the per-channel software state; a positive sensor reading cannot prove that every nozzle seated a tip.

print("hardware tip presence:", await head.has_tip_on_hardware())
print(
  "channels with tips:", [i for i, tip in enumerate(head.get_mounted_tips()) if tip is not None]
)

Aspirate a full column#

Volumes are per active nozzle: 20 µL here means 160 µL across eight wells. plate.column(0) supplies the well list. The explicit flow_rate=10 is in µL/s. liquid_height=1 places the nominal pipetting point 1 mm above the well bottom; choose a height that is submerged and clear of the bottom for your real labware. An optional offset=Coordinate(x=0, y=0, z=...) adjusts that point in mm (import Coordinate from pylabrobot.resources).

When flow_rate is omitted, the driver looks up defaults for the discovered pipette model and mounted tip capacity. head.default_flow_rates() reports them after pickup; an unsupported model raises instead of guessing.

print("default flow rates:", head.default_flow_rates())
await head.aspirate(plate.column(0), volume=20, flow_rate=10, liquid_height=1)

Dispense back into the source column#

Return 20 µL per nozzle to A1–H1. use_channels on a liquid operation must match all mounted channels; it cannot turn off some nozzles after a full-column pickup. Omitting it uses the mounted channels.

await head.dispense(plate.column(0), volume=20, flow_rate=10, liquid_height=1)

Optional: touch the well walls#

With the full column still mounted, touch_tip() touches the well walls using the labware geometry. The 8-channel method takes the plate and a column index; radius is a fraction of the well radius, not a distance in mm. Skip this cell unless the well geometry and clearance are appropriate for your tips.

await head.touch_tip(plate, column=0, radius=0.8)

Optional: probe for liquid#

With the full column mounted, try_liquid_probe() reports the detected liquid Z position in mm, or None when none is detected. liquid_probe() instead raises when no liquid is found. This is an active probe motion, not a cached volume reading. The reported Z position is not automatically a well-relative liquid_height; do not substitute it directly into aspiration parameters.

liquid_z = await head.try_liquid_probe(plate, column=0)
print("detected liquid Z:", liquid_z)

Discard the full column#

Discard into the trash configured by FlexDeck at A3. The hardware sensor is checked after dropping; investigate a warning about a retained tip before continuing. For a full column that should be returned to its original empty rack column, await head.drop_tips(tip_rack, column=0) is an alternative to this discard cell. Do not run both alternatives for the same mounted tips.

await head.discard_tips(trash)
print("after drop:", await head.has_tip_on_hardware())

Single nozzle: pick up one tip on H1#

Channel 7 is the front H1 nozzle. Picking tip-rack A2 places that tip on H1; the tip’s well name does not select the nozzle. The other seven nozzles overhang behind row A of the rack, into the clear space behind D1.

Only channels 0 (A1 nozzle) and 7 (H1 nozzle) can anchor a single-tip layout. The nozzle layout is chosen at pickup and stays fixed until tips are discarded.

await head.pick_up_tips(tip_rack.get_item("A2"), use_channels=[7])
print("mounted tips:", head.get_mounted_tips())

Aspirate from one well#

Use a single Well target with the single tip. The plate is in B1 and A1 is empty, providing clearance behind the target for the inactive nozzles.

await head.aspirate(
  plate.get_item("A1"), volume=20, use_channels=[7], flow_rate=10, liquid_height=1
)

Dispense into one well#

Return the liquid to A1. The explicit channel list is optional when it matches the mounted tip; the driver also infers it from the pickup.

await head.dispense(
  plate.get_item("A1"), volume=20, use_channels=[7], flow_rate=10, liquid_height=1
)

Discard the single tip#

discard_tips(trash) works for the single-nozzle layout too. It drops the tip before restoring the full layout. The driver does not support returning this single tip with the full-column rack-drop method.

await head.discard_tips(trash)

Optional: pick up a partial column#

This example picks A4–D4 onto the front four nozzles E1–H1, channels [4, 5, 6, 7]. A partial selection must be contiguous and include one end of the head. Here H1 is positioned over D4; the unused rear nozzles remain behind row A of the rack. Keep C1 clear.

Do not substitute column(3)[4:8] on a full rack: that would leave unused nozzles above tips in A4–D4. Treat this as a bench-validation step; confirm the physical alignment and watch the pickup.

This section demonstrates pickup and discard only. The current well-list aspirate/dispense path requests the full nozzle layout, so partial-column pipetting is not demonstrated or promised by this guide.

await head.pick_up_tips(tip_rack.column(3)[:4], use_channels=[4, 5, 6, 7])
print(
  "channels with tips:", [i for i, tip in enumerate(head.get_mounted_tips()) if tip is not None]
)

Discard the partial column#

Discard all four mounted tips before continuing or switching layouts.

await head.discard_tips(trash)

Optional: move a plate with the gripper#

Skip these cells if no gripper is installed. Finish pipetting and discard all tips first. Confirm the plate is suitable for gripping, its definition and calibration match the physical plate, and B2 and the travel path are clear. move_labware() performs pickup, travel, and placement, and updates PLR’s deck location after success. The gripper cannot rotate labware.

Keep the plate in the same orientation. Do not change its PLR slot manually before asking the gripper to move it.

if flex.gripper is not None:
  await flex.gripper.move_labware(plate, to_slot="B2")
  print("plate slot:", deck.get_slot(plate))
else:
  print("No gripper installed; skipping plate move.")

Return the plate to B1#

Confirm B1 is still clear, then restore the example’s deck layout.

if flex.gripper is not None:
  await flex.gripper.move_labware(plate, to_slot="B1")

Shutdown and release control#

After a successful run, stop() discards any tracked mounted tips, homes the robot, cancels its run, and closes the connection. It moves hardware.

If a failure leaves the physical state uncertain, inspect it before requesting further motion. await flex.disconnect() cancels this object’s run and closes its connection without homing or dropping tips; it does not remove physical tips or make a failed motion safe. A connection created only with connect() can also be released this way. Keep the flex object until its run is released.

await flex.stop()

Additional operations and troubleshooting#

The Flex API reference describes the full method signatures. These operations require a protocol tailored to your deck:

Task

API and constraints

Reservoir pipetting

head.aspirate(container, volume=...) / dispense(...); the single cavity must accommodate all active tips, and its volume tracker changes by volume × active channels.

In-place pipetting

aspirate_in_place, dispense_in_place, air_gap_in_place, and blow_out act at the current position. Position the head deliberately; they do not target a well for you.

Position and motion

position, move_to, move_to_well, move_relative, and move_to_addressable_area; follow the method’s frame and clearance rules.

Pipette configuration

configure_for_volume and prepare_to_aspirate; support and hardware validation depend on the operation and robot software.

Robot controls

set_rail_lights, set_status_bar, add_comment, and wait_for_duration. Direct axis methods and send_command require explicit protocol knowledge.

Labware changes

sync_tips_to_robot, labware_moved_off_deck, and reload_labware keep the active run consistent after intentional resource changes.

Other heads

A FlexHead1 uses individual tip spots and wells; FlexHead96 uses rack/plate-wide operations. Check their signatures and verification status rather than reusing this 8-channel protocol.

  • No robot found: check that the robot and computer share a network with mDNS multicast allowed. Try its known IP if discovery is blocked.

  • More than one robot found: use find_flex_ip(name="My Flex").

  • Wrong or missing head: check the selected mount and installed pipette.

  • Missing tips or insufficient liquid: reconcile the real deck and PLR trackers. Do not disable tracking merely to retry a failed command.

  • Layout or clearance error: discard mounted tips before changing nozzle layouts and check the empty adjacent slots and tip selection.

  • Unknown default flow rates: choose explicit rates validated for the pipette, tip, and liquid instead of substituting a different model’s defaults.

  • Robot remains in use: release the run through the existing flex object; creating another Python object does not release the previous run.

To repeat the full guide, restore the physical rack and water volumes, release the previous run, and then rebuild the resources. Tracking state must match the physical deck at the start of each pass.
