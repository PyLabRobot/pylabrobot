pylabrobot.paa.kx2.KX2#

class pylabrobot.paa.kx2.KX2(has_rail: bool = False, has_servo_gripper: bool = True, interface: str | None = None, channel: str | None = None, bitrate: int = 500000, gripper_length: float = 0.0, gripper_z_offset: float = 0.0, gripper_finger_side: Literal['barcode_reader', 'proximity_sensor'] = 'barcode_reader', barcode_port: str | None = None, barcode_baudrate: int = 9600, parking_position: Dict[Axis, float] | None = None)#

Bases: object

PAA KX2 robotic plate handler.

A single class spanning CAN transport + Elmo drive primitives and the robot-level arm/gripper/homing/kinematics logic. Construct it, await setup(), drive it, await stop().
