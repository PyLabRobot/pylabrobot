pylabrobot.high_res.sample_storage.AmbiStore#

class pylabrobot.high_res.sample_storage.AmbiStore(host: str, name: str, racks: Mapping[int, PlateCarrier] | None = None, size_x: float = 0, size_y: float = 0, size_z: float = 0, rotation: Rotation | None = None, category: str | None = 'plate_store', model: str | None = None, port: int = 1000, read_timeout: float = 30.0, motion_timeout: float = 240.0, nests: Sequence[PlateHolder] | None = None, barcode: Barcode | None = None, preferred_pickup_location: Coordinate | None = None, metadata: Mapping[str, Any] | None = None)#

Bases: HighResSampleStorage

HighRes Biosolutions AmbiStore plate store.

The AmbiStore is ambient, so it exposes only plate storage and retrieval. Its environment-control behavior has not yet been verified against hardware.
