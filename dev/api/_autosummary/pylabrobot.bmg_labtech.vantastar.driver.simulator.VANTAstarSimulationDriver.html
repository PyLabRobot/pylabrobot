pylabrobot.bmg_labtech.vantastar.driver.simulator.VANTAstarSimulationDriver#

class pylabrobot.bmg_labtech.vantastar.driver.simulator.VANTAstarSimulationDriver(declared_configuration_json: str, name: str = 'VANTAstar')#

Bases: VANTAstarDriver

A VANTAstar driver with no reader behind it.

Nothing reaches a wire. The configuration comes from declared_configuration_json; status comes from the simulated state; the drawer moves, the shaker shakes and the temperature controller reaches its target at once. Reads return random values or simulated_data.
