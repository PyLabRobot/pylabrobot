# BDZ test data

`presto_mix.bdz` is a synthetic regression fixture generated by this package's
`write_bdz()` from the test protocol in `bdz_tests.py`. It contains Wash and Elute
Mix steps, two sample plates, and a 12.5 µL reagent volume.

It is not a BindIt export or a hardware capture. The Presto interface specification
and the original manufacturer-generated Presto/Duo BDZ examples are not available
in this repository. Tests establish software behavior only; instrument acceptance,
feature-report details, and compatibility with manufacturer files need verification.
